## Сверх минимума

- предпросмотр улучшенного текста со сравнением «было / стало»;
- ручная правка текста перед скачиванием (сценарий 7);
- голосовой ввод черновика — локальный Vosk, без внешних сервисов;
- загрузка и автоматический разбор произвольного DOCX-шаблона;
- бот в мессенджере MAX — тот же сценарий вторым каналом;
- журнал обработки `GET /api/trace/{id}` и dev-панель;
- имитация отказа ИИ по кнопке для демонстрации сценария 6;
- кэш результатов обработки по содержанию черновика;
- 16 демонстрационных черновиков организаторов и 8 эталонных DOCX.

## Ограничения

**Обработка идёт 20–60 секунд.** Локальная 7B-модель на CPU. С GPU
быстрее, но GPU не требуется. Интерфейс всё это время показывает стадию
обработки, а не пустой экран.

**Fact Guard работает на регулярных выражениях, а не на NER.** Это
сознательный размен: 80% результата за 20% времени. Следствия:

- организация без кавычек и без организационно-правовой формы («Поставщик
  ТехноСнаб») не попадает в якоря;
- фамилия без инициалов и без отчества не распознаётся как ФИО;
- сумма прописью («сто восемьдесят тысяч рублей») не сверяется с цифровой.

Ни одно из этих ограничений не приводит к ложной блокировке — только к
тому, что часть фактов не под защитой Guard. Направление развития —
добавить NER-слой (Natasha) поверх регулярок.

**Номер документа не автозаполняется.** Организаторы разрешают
порядковый номер, но у номера нет достоверного источника: формат зависит
от номенклатуры дел организации. Реквизит уходит со статусом `missing` —
пользователь вводит свой либо документ остаётся с явной пометкой.

**Разбор загруженного DOCX не определяет расположение реквизитов.** Из
файла вычитываются поля, шрифты, интервалы и колонтитулы; раскладка
берётся от классического шаблона и правится в `rules.yaml`. Определить по
абзацам, какой из них «адресат», без разметки нельзя.

**Журнал обработки живёт в памяти процесса.** Он нужен для проверки и
демонстрации, а не для аудита: после перезапуска пуст.

**Один пользователь.** Аутентификации нет — задание прямо это разрешает.
Документы не разделены по владельцам: тот, у кого есть ссылка, видит
документ.

**Распознавание речи — модель `vosk-model-small-ru`.** Компактная и
быстрая, но на шумной записи ошибается. Расшифровка попадает в черновик,
где её можно поправить руками до обработки.

**Голосовой ввод требует защищённого соединения.** Доступ браузера к
микрофону (`getUserMedia`) работает только на `https://` или `localhost` —
это ограничение браузера, не приложения. Боевой `compose.prod.yml` поднимает
фронт по HTTPS, поэтому на стенде микрофон доступен; при открытии по
`http://<IP>` кнопка микрофона будет неактивна, а ввод текстом и вставка из
буфера работают всегда.

**Проверка орфографии — только через модель.** Отдельного словарного
спелчекера нет: резервный слой чинит пунктуацию, регистр и просторечия по
словарю, но опечатки в редких словах не исправит.
